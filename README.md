# PPT 风格克隆 (ppt-style-clone)

一键复刻 PPT / PDF / 截图的视觉风格与排版，把**你自己的内容**重排成同风格、可继续编辑的 HTML 文件。重点是「套风格」而不是抄内容。

> 为什么是 HTML 而不是 PPTX？HTML 有像素级控制权，能精确还原满底色、超大章节数字、竖排描边标题等标志性元素；还能在本地用无头浏览器渲染自检排版，不必靠人工逐页核对。

## 适用场景

- 你有一份好看的参考 PPT / 宣传册 / 画册，想把它那套设计语言套到自己的内容上。
- 典型说法：「复刻这个 PPT 风格」「照着这份套个新的」「套用 XX 排版」「克隆这份画册的版式」。

## 输入

- **参考来源（满足其一）**：本地 `.pptx` 原件、PDF、截图图片。原件能精确读样式，PDF / 截图靠视觉分析还原。
- **你的内容（满足其一）**：现成大纲（每页标题+要点，严格照填）、一篇长文档 / Word / Markdown（AI 提炼拆页）、零散要点 / 主题（AI 扩写成完整 PPT）。内容偏少时 AI 会主动补充使其饱满。

## 工作流

1. **澄清与准备**：确认要「保持跨页双页」还是「改成标准 16:9 单页」；建立项目目录。
2. **提取参考风格**：把参考渲染成图，产出《风格档案》——配色板、字体气质、版式网格、**标志性元素**（最容易忽略但最定义风格的部分）、页面类型清单。
3. **提取并扩写内容**：大纲照填 / 长文拆页；偏少则补充分论点、示例、数据占位（不编造假数据）。
4. **构建 HTML**：以 `references/html-template.html` 为骨架，用 CSS 逐页复刻标志性元素。
5. **本地自检验排版**：Chrome 无头渲染 → PDF → 逐页 PNG → 自检修正。
6. **交付与迭代**：预览、按反馈改到满意，可再导出 PDF。

## 文件结构

```
ppt-style-clone/
├── SKILL.md                      # 主文件：触发条件 + 工作流 + 质量线 + 陷阱 + 示例
├── references/
│   ├── style-extraction.md       # 如何从 PDF / PPTX / 截图提取《风格档案》
│   ├── html-template.html        # 可直接复用的 HTML 骨架（跨页版式 + 竖排 CONTENTS + 超大章节数字 + 双白线 + 打印 CSS）
│   └── content-augmentation.md   # 内容偏少时如何合规补全、不编造假数据
├── _skillhub_meta.json           # （可选）发布到 SkillHub 用的元数据，其他环境可忽略或删除
└── README.md
```

## 安装

这是一个标准的 agent skill（以 `SKILL.md` 为核心）。把它放到你所用 AI 编程助手的 **skills 目录** 下即可被自动发现，目录名保持 `ppt-style-clone`：

```
<你的助手 skills 目录>/ppt-style-clone/
├── SKILL.md
├── references/
└── README.md
```

> 不同助手的 skills 目录位置不同，放进去后通常刷新 / 重启会话即可生效。`_skillhub_meta.json` 是给 SkillHub 平台用的发布元数据，在其它环境里不影响 skill 运行，可保留也可直接删除。

## 质量线

- 配色、字体气质与参考高度一致；**标志性元素被精确复刻**，不是「好看但根本不像」的通用模板。
- 版式尽量照搬参考，但按你的内容灵活适配，整体和谐、无硬搬导致的拥挤或留白失衡。
- AI 已用截图自检过每页排版，无溢出、无元素错位。
- 内容完整饱满；补充内容贴题、不编造假数据 / 人名 / 权威数字。

## 设计原则（踩坑沉淀）

1. **先抓标志性元素再严格复刻**，不擅自替换成自创模板。
2. 用**单文件 HTML** 而非 PPTX 管线，从根上避免页面追加导致的页数错乱。
3. **必须无头截图自检**，不让用户当眼睛。
4. **真实图片优先复用**，不滥用生图。
5. 识别**跨页结构**：宣传册是左右对开面，不当成独立单页处理。
